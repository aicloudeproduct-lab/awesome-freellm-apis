# «Өміріңді өзгертетін 8 қадам» — iPad 4:3, 25 с

2048×1536, 30 fps (750 кадр), H.264 + AAC. Showreel эстетикасы: ірі типографика, қара/жылы ақшыл фондардың
ырғақты алмасуы, лайм / күлгін / қызғылт сары акценттер, WebGL-дегі сұйық металл мен хром пішіндер.

## Құрылым
- `scene/index.html, scene.js` — 2D Canvas сахнасы; `renderFrame(t)` кез келген сәтті тәуелсіз салады.
  Браузерде ашсаң, нақты уақытта ойнайды; `index.html?t=12.5` — бір кадр.
- `scene/metal.js` — хром/сұйық металл (WebGL2 raymarching, процедуралық студия жарығы).
- `scene/fonts/` — Inter Display Black/Bold, Inter Medium (SIL OFL), қазақ әріптері толық.
- `tools/render.mjs` — кадрлар → `frames/` (бар кадрды өткізеді: үзілсе, жалғасады). `--times 1,5.5` → `tests/`.
- `tools/make_music.py` — 120 BPM түпнұсқа электрондық трек → `audio/music.wav` (numpy + scipy).
- `tools/encode.sh` → `out/8-qadam-ipad-25s.mp4`; `tools/verify.py` — тексеру; `tools/contact.py` — кадр парағы.

## Қайта жасау
```bash
node tools/render.mjs --workers 4     # ~5 мин
python3 tools/make_music.py
bash tools/encode.sh
python3 tools/verify.py out/8-qadam-ipad-25s.mp4
```
