# Lihenologiya_Muk_AI_15_Slide.html

«Қыналар, мүктер және жасанды интеллект» — 15 беттік анимациялық HTML-презентация (бір файл, интернетсіз ашылады).

**Басқару:** ← / → (немесе бос орын), Home / End, iPad-та саусақпен сырғыту.
`N` — жүргізуші жазбалары, `A` — автоойнату, `P` — анимацияны тоқтату, `M` — қозғалысты азайту, `F` — толық экран.
`#7` сияқты сілтеме бірден 7-бетті ашады.

**Ресми эмблема:** файлға енгізілмеген (университет сайты бұл ортадан қолжетімсіз болды).
Қосу үшін: 1-беттегі «Ресми эмблема» шеңберін басып, ресми PNG/SVG файлын таңдаңыз
(сол браузерде сақталады), немесе файлды `buketov-emblem.png` атымен HTML-дің жанына қойыңыз.

**Кейіпкер:** тіркелген суреттен қиып алынған 2.5D қабаттар (дене, бас, көз қағу кадры).
Бұл айналатын толық 3D модель емес: тыныс алу, көз қағу, бас изеу, бұрылу және қадам қимылдары қабаттарды жылжыту арқылы жасалған.
