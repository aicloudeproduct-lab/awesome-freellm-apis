# Екі терезе — 3D анимациялық қысқаметражды фильм

Тақырып: «Жігіттің өзімен тартыссаң да, бағымен тартыспа». Сәулетші Арман бала
кезгі досы Аянның жетістігін көре алмай, түнде оны жамандайтын пост жазады.
Ұлы перденің жабады, сонда Арман бәрін түсінеді: постты өшіріп, досынан кешірім
сұрайды, үйіндегі өз несібесін көре бастайды.

**Нәтиже:** `output/final.mp4`
- 2160×3840 (9:16), тұрақты 24 fps, 124 с (2976 кадр), H.264 High, yuv420p;
- AAC stereo 48 kHz, faststart;
- −16.0 LUFS, true peak −1.4 dBTP;
- 89.9 MB: екі өтімді кодтау, 5.6 Mbit/s, GitHub-тың 100 MB шегіне сыю үшін.

`tools/verify.py` тексерісінің нәтижесі — **PASS**:
- spec және faststart дұрыс;
- үнсіз бөлік жоқ, қара кадр жоқ;
- бір кадрлық глитч жоқ.

Түс секірістерінің бәрі жоспарланған монтаж нүктелерінде: кесулер, флеш, dissolve, перде-wipe және соңғы fade.

Жоғары сапалы мастер (CRF 19, 325 MB) репозиторийге сыймайды.
Оны `bash tools/render_final.sh` жасайды, ал `bash tools/encode_delivery.sh` одан осы нұсқаны алады.

`output/contact_sheet.jpg` фильмнен әр 2 секунд сайын алынған бір кадрды көрсетеді.

> **Шектеулер (ашық айтамын)**
> - **Сілтеме видео жоқ.** reference.mp4 берілмеді, сондықтан стиль брифтің сипаттамасы бойынша жасалды.
> - **3D қабат 1440×2560-та рендерленіп, 2160×3840-қа Lanczos-пен үлкейтілді.**
>   Себебі рендер GPU-сыз жүреді (SwiftShader, 4 CPU ядро). 4K кадр ≈17 с, 1440 кадр ≈9 с,
>   ал 2976 кадр бар. Мәтін қабаты (субтитр, тақырып, соңғы ой) нағыз 4K-да салынып,
>   үстінен қойылды, сондықтан қазақша мәтін анық.
>   `SCENE_W=2160 tools/render_final.sh` командасы 3D қабатты да нағыз 4K-да рендерлейді.
> - **Стиль — «жартылай реалистік» 3D, фотореализм емес.**
>   - Денелер MakeHuman (CC0) базалық мешінен шығарылған: қаңқа, салмақтар, 16 бет мимикасы.
>   - Шаш, киім, бет терісі процедуралық түрде жасалған: Three.js рендері, PBR материалдар,
>     DOF, көлеңке, грейдинг.
>   - Нақты шаш/мата симуляциясы мен субсерфейс жоқ. Қол саусақтары IK мен бүгуден тұрады,
>     сондықтан жақын кадрларда қаттылық байқалады.
> - **Дауыс — синтезделген.** Дауыстарды Piper TTS береді (ISSAI қазақ моделі, 6 диктор).
>   Кейіпкерлер үшін биіктік пен тембр өзгертілді. Айтылымды құлақпен немесе ASR-мен тексеру
>   мүмкін болмады (ортада тыңдау жоқ, ASR хосттары жабық). Мәтін брифтегі сөздермен дәл сәйкес.
>   Ерін қозғалысы әр репликаның дыбыс амплитудасы мен дауысты/дауыссыз белгісінен
>   24 fps-та есептеледі. Бұл фонемалық lip-sync емес.

## Қайта рендерлеу

```bash
cd eki-tereze
npm install                      # three, playwright-core, esbuild
bash tools/render_final.sh       # 3D қабат (бөліктермен) → мәтін қабаты → дыбыс → композиция → mux
mv output/final.mp4 output/final_master_crf19.mp4 && bash tools/encode_delivery.sh   # ≤100 MB нұсқа
python3 tools/verify.py          # ffprobe, LUFS/true peak, үнсіздік, қара кадр, глитч кадр, contact sheet
```

`render_final.sh` қайта жалғанады. Әр 300 кадрлық бөлік `build/final/scene_NNNN.mp4`
ретінде сақталады. Үзіліп қалса, сол команданы қайта іске қосыңыз: дайын бөліктер өткізіліп
жіберіледі. Толық рендер 4 CPU ядрода шамамен 6 сағат алды (бір кадр ≈7.5 с).

| Команда | Не істейді |
| --- | --- |
| `npm run still -- 63.2,107 --out a.jpg,b.jpg` | Жеке кадрлар (540 px), уақыты секундпен |
| `npm run preview` | Жеңіл preview (360×640, 12 fps, дыбыссыз) → `build/preview.mp4` |
| `npm run chars` | MakeHuman деректерінен 9 кейіпкерді құрастыру → `assets/chars/` |
| `npm run voice` | Репликаларды Piper-мен синтездеу → `build/voice/*.wav`, `build/voice.json` |
| `npm run score` | Музыка, фоли, амбиенс, микс → `build/audio/master.wav` (−16 LUFS) |

Рендер жөндеу флагтары (`--flags a=1&b=1`):
- `nodof`
- `noshadow`
- `override`
- `nochars`
- `nolights`
- `nocornea`
- `prof` (уақыт пен жарық санағы)
- `layer=scene|text`

### Талаптар

- Node 18+, FFmpeg (libx264, librubberband).
- Chromium headless_shell. Жолы `tools/render.mjs` ішінде көрсетілген, басқа ортада өзгертіңіз.
- Python 3: `numpy scipy pillow pyloudnorm`.
- Кейіпкерлерді қайта құру үшін MakeHuman `makehuman/data` керек:
  `git clone --depth 1 --filter=blob:none --sparse https://github.com/makehumancommunity/makehuman.git`,
  одан кейін `git sparse-checkout set makehuman/data`, соңында
  `third_party/makehuman` → `.../makehuman/data` сілтемесін жасаңыз (немесе `MH_DATA=...`).
- Дауысты қайта синтездеу үшін `pip install piper-tts` және
  [voice-kk-issai-high.tar.gz](https://github.com/rhasspy/piper/releases/download/v0.0.2/voice-kk-issai-high.tar.gz)
  керек; оны `voices/` ішіне ашыңыз.
  Дайын дауыс файлдары `build/voice/` ішінде репозиторийге енгізілген,
  сондықтан фильмді рендерлеу үшін модель қажет емес.

## Сценарий мен уақыт

| Уақыт | Бөлім | Не болады |
| --- | --- | --- |
| 0–10.6 | Түн | Телефон жарығындағы бет, жала пост, терезеден Аянның үйі, «Жариялау», баланың қолы пердеге созылады |
| 10.6–25 | Балалық, студенттік шақ | Балшық үй → макет (dissolve), жатақхана, сызба сызықтары → 3D ғимарат |
| 25–43 | Байқау | Қазылар, Аян жеңеді, «Құттықтаймын, досым!», Аянға тапсырыс, Арман өз жұмысында |
| 43–65.4 | Қызғаныш | Марапат, кубок шағылысы → телефон экраны, лента, қабылданбаған қоңырау, терезе жақтауынан өткенде мезгілдер ауысады, ТД |
| 65.4–83.4 | Үй | Әйелінің шайы, «Әке, біздің үйді салдым. Қарашы!», «Қазір, балам…», сурет үстелде қалады, Арман терезеге қарайды |
| 83.4–101 | Қайтадан түн | Перде камераны жауып қазіргі уақытқа қайтарады, баланың сұрағы (музыка тынады), Арман постты өшіреді, «Көрсетші, балам…» |
| 101–114.2 | Есік алдында | Есік қағу, «Сен маған жамандық жасаған жоқсың… Кешір.», «Мен сені ренжітіп алдым ба деп ойлап жүрдім.» |
| 114.2–124 | Соңы | Аянды құттықтау хабары, баласымен сурет салу, суреттегі екі терезе → Аянның жарық терезелері мен Арманның жылы бөлмесі, соңғы ой |

Түс драматургиясы:
- балалық шақ жылы;
- қызғаныш күшейген сайын суыта түседі (үй жарығы бәрібір жылы);
- соңы табиғи.

Музыка:
- фортепиано мен ішекті аспаптар;
- қызғаныш бөлімінде төмен тондар;
- баланың сұрағында ducking пен тыныштық;
- соңында үміт.
