# «Өміріңді өзгертетін 8 қадам» — видео жобасы

Тік видео 1080×1920, 30 fps, 32 с, H.264 + AAC. Бәрі кодпен жасалған: сахна — HTML/Canvas/CSS 3D,
кадрлар — Chromium (Playwright), кодтау — ffmpeg, музыка — numpy-мен синтезделген түпнұсқа дыбыс.

## Құрылым
- `scene/index.html, style.css, scene.js` — сахна. `renderFrame(t)` кез келген уақыт сәтін тәуелсіз салады.
  Браузерде ашсаң, нақты уақытта ойнайды; `index.html?t=12.5` — бір сәтті көрсетеді.
- `scene/fonts/` — Inter Display / Inter (SIL OFL), қазақ әріптерінің бәрі бар.
- `tools/render.mjs` — кадрлар → `frames/`. Бар кадрларды өткізіп жібереді, сондықтан үзілсе, қайта іске қоссаң жалғасады.
- `tools/make_audio.py` — музыка → `audio/music.wav`.
- `tools/encode.sh` — `out/8-qadam.mp4`.
- `tools/verify.py` — метадеректер, қара кадрлар, секірістер, бақылау кадрлары.
- `tools/contact.py` — кадрларды бір параққа жинау.

## Қайта жасау
```bash
node tools/render.mjs --workers 4        # ~15 мин, 960 кадр
python3 tools/make_audio.py
bash tools/encode.sh
python3 tools/verify.py out/8-qadam.mp4
```
Сынақ кадрлары: `node tools/render.mjs --times 1,5.5,25` → `tests/`.

## Уақыт сызығы
| Уақыт | Көрініс |
|---|---|
| 0–4 с | Жарық «8» салынып, 8 түйінді жолға айналады; «Өміріңді өзгертетін / 8 қадам», «Өзгеріс өзіңнен басталады» |
| 4–24 с | 8 қадам × 2,5 с; жол төмендегі прогресс сызығына айналады, ноутбук экранында әр қадамның интерфейсі |
| 24–29 с | Прогресс түйіндері 8 мини-экранға айналып, жоғары көтерілетін жолды құрайды; «Үлкен өзгеріс — күнделікті шағын әрекеттен» |
| 29–32 с | Артық бөлшектер кетеді, нүкте бір баспалдақпен көтеріледі; «Бүгін бір қадам жаса» |
