# Бес уақыт — motion piece

Минималистік ақ сызықты адам ауыр рюкзакпен жар үстіндегі аспалы көпірден өтеді.
Әр намаз сәтінде рюкзактан бір символдық тас түседі («Өкініш», «Уайым», «Реніш»,
«Жаман әдет», «Өткеннің жүгі»), жүрісі мен денесі біртіндеп жеңілдейді; таңнан
құптанға дейін жарық өзгереді. Дикторсыз, дыбысы толық синтезделген.

**Нәтиже:** `output/final.mp4` — 1080×1920, 60 fps, 20 s, H.264 (yuv420p),
AAC stereo 48 kHz, faststart.

## Қайта рендерлеу

```bash
cd bes-uaqyt
npm install
bash tools/render_final.sh        # rig QA → events → audio → render → mux → verify
```

Бөлек қадамдар:

| Команда | Не істейді |
| --- | --- |
| `npm run studio` | Remotion Studio-да интерактивті көру |
| `npm run check` | Rig тексерісі: сүйек ұзындығы, аяқ сырғуы, тақтайға ену, буын секіруі, рюкзак |
| `npm run events` | Қимылдан дыбыс оқиғаларын шығару → `build/events.json` |
| `python3 tools/make_audio.py` | Дыбысты синтездеу → `build/audio/master.wav`, `public/audio/mix.wav` |
| `npm run preview` | Жеңіл preview (540×960, дыбыссыз) → `output/preview.mp4` |
| `tools/stills.sh 30 400 …` | Толық өлшемді жеке кадрлар → `build/stills/` |
| `python3 tools/verify.py output/final.mp4` | ffprobe, LUFS/true peak, үнсіздік, қара кадр, түс секіруі, contact sheet |

Талаптар: Node 18+, FFmpeg, Python 3 (`numpy scipy pillow pyloudnorm`).
Chromium жолы `remotion.config.ts` ішінде (`setBrowserExecutable`) — басқа ортада
оны алып тастаңыз немесе өзгертіңіз.

## Өңдеу қайда

| Файл | Мазмұны |
| --- | --- |
| `src/config/timeline.ts` | Барлық тайминг: жүрістер, намаз сәттері мен поза кілттері, финал, камера, мәтін уақыты, rig пропорциялары, көпір |
| `src/config/palette.ts` | Алты уақыттың түстері (OKLab-та араласады), күн/ай/жұлдыз параметрлері |
| `src/config/text.ts` | Барлық мәтін, қаріп өлшемдері мен салмақтары |
| `src/config/audio.json` | Дыбыс деңгейлері, реверб, аккордтар, LUFS мақсаты |
| `src/motion/*` | Rig (FK + екі буынды IK), жүру жоспары, көпір иілуі, рюкзак серіппесі, тастар, камера |
| `src/scene/*` | SVG қабаттары: аспан, жоталар, тұман, жартастар, көпір, кейіпкер, мәтін |

Барлығы кадр нөмірінен есептеледі, кездейсоқтық seeded — рендер қайталанғанда бірдей.
Қаріп (Noto Sans variable, OFL) және дыбыс жергілікті; рендер сыртқы URL-ге тәуелді емес.

## Ескерту

Тапсырмада аталған `reference.mp4` жобаға тіркелмеген (репозиторийде де, жүктелген
файлдарда да жоқ), сондықтан видео кадрма-кадр талданбады. Визуалдық тіл тапсырмадағы
референс сипаттамасы бойынша жасалды.
